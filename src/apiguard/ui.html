APIGuard

Claude generates a test suite once. APIGuard saves it and replays it on the original application and on versions with seeded faults, without calling the AI model again.

1Generate tests

Claude reads the selected OpenAPI operations and the seed-data notes, and writes test definitions. Each definition is checked against the specification before it is saved.

2Application version

NexStock runs in Docker with fixed seed data. Each seeded fault is one small patch to the original code. Switching restarts the API container.

3Run the suite

Resets the seed data, logs in as each role and replays every saved request. The AI key is removed from the run's environment.

4Compare runs

A fault is detected when a test that passes on the original application fails on the faulted version.

5Evaluation against Schemathesis

Both tools run on the original application and on each seeded fault, using the same specification snapshot.
